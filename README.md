# AI-Powered Computer Vision System for Automated Quality Control and Defect Detection

Final-year B.Sc. (Hons.) Data Science project.
Detects surface defects using YOLO, stores inspections in SQLite, and shows analytics in a Streamlit dashboard.

## Status
Work in progress. Phase 2 (environment setup) complete.

## Setup (Windows)
```
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
```
